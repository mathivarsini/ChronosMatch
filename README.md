# ChronosMatch

A Python learning project exploring a memory-mapped
ring buffer for high-frequency order processing.

## Features
- Binary order records using Python struct
- Memory-mapped storage using mmap
- Ring-buffer read and write pointers
- FIFO ordering and wraparound
- Automated tests
- Basic performance benchmarking

## How to Run Tests
```powershell
python lesson23_test_suite.py
```

## How to Run the Benchmark
```powershell
python lesson24_benchmark.py
```
